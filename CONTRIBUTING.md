# Contributing to Higher Math for the Impatient

Thank you for helping make advanced mathematics clearer, more precise, and more inviting.

## Reporting mathematical errors

Please open an issue and include:
- **Book**, **edition**, **page number** and equation/figure reference, if relevant.
- What appears incorrect, with an explicit counterexample or derivation if possible.
- A minimal proposed correction and any useful references.

Label the report **mathematics**, **typo**, **exposition**, **exercise**, or **code** as appropriate (repository maintainers can create and assign these labels).

## Proposing improvements

We welcome particularly clear motivating examples, complete solutions to short exercises, mathematically informative diagrams, and small executable programs with tests. It is useful to explain *why* a proposed change improves a reader's understanding, not just that it differs from the current text.

## Website pull requests

1. Fork the repository and create a descriptive branch.
2. Change only the site files needed for your improvement; avoid unrelated design changes.
3. When adding a volume, include its PDF, a cover preview, and accurate metadata in `assets/js/books.js`.
4. Check all relevant links, readers, downloads, and responsive layout locally.
5. Open a pull request describing what changed and how it was tested.

**PDF manuscript changes:** Please open an issue first unless the relevant book's source repository explicitly invites text pull requests. The source manuscript remains authoritative; a revised PDF should be built from that source, with author approval and edition tracking.

**Companion code:** Send code changes to the book's associated laboratory repository, not the library website, unless the contribution concerns the reader/site itself.

## Editions and attribution

Do not silently overwrite a published PDF with an unreviewed version. Keep author and coauthor credits exact; identify when a booklet is a working or prepublication edition. If a revised edition replaces a PDF snapshot, describe the change in the pull request.

## Rights

These book PDFs have not been assigned a new open license by this repository. Contributors retain rights to their submissions; inclusion in revised book editions requires any necessary permission or agreement with the relevant authors. Do not assume the current PDFs may be repackaged or sold under an open-content license.

Be rigorous, specific, respectful, and willing to revise an argument if someone finds a counterexample.
